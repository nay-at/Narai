# Dialogue


**田中先生** : おはようございます。 
**マリーさん** : おはようございます、先生。 
**田中先生** : 失礼ですが、お名前は？ 
**マリーさん** : 私の名前はマリーです。初めまして。 
**田中先生** : 初めまして。どうぞよろしくお願いします。こちらは佐藤さんです。佐藤さんは銀行員です。 
**佐藤さん** : 初めまして。どうぞよろしく。 
**田中先生** : マリーさん、どちらから来ましたか？ 
**マリーさん** : フランスから来ました。 
**佐藤さん** : そうですか。おいくつですか？ 
**マリーさん** : 二十四歳です。佐藤さんは何歳ですか？ 
**佐藤さん** : 私は三十二歳です。 
**田中先生** : マリーさんは大学で何を勉強していますか？ 
**マリーさん** : 日本語を勉強しています。 
**佐藤さん** : すごいですね。他の言語も話せますか？ 
**マリーさ** : はい、フランス語と英語を話せます。中国語と韓国語は少し分かります。 
**田中先生** : どなたが中国語を教えましたか？ 
**マリーさん** : 中国人の友達です。彼は中国から来ました。 
**佐藤さん** : 韓国にも行ったことがありますか？ 
**マリーさ** : いいえ、まだです。でも韓国人の友達がいます。 
**田中先生** : イギリスはどうですか？ 
**マリーさ** : はい、イギリスに住んでいました。家はロンドンにありました。 
**佐藤さん** : 日本はどうですか？どこが好きですか？ 
**マリーさ** : 日本がとても好きです。この国は美しいです。

# Grammaire

- ***は***
    - **Explications :** Marque un thème. Implique quelqu'un ou quelque chose auquel on donne une explication ou une question, ou implique un contraste.
    - **Structure :** N**は**N ...
    - **Templates :**
	    - [Name]さん**は**[Job]です。
        - 私**は**[Age]歳です。
        - [Place]**は**どうですか？
        

- ***が***
    - **Explications :** Marque le sujet grammatical. Utilisé pour identifier, présenter ou mettre l'accent sur qui/quoi fait l'action. Souvent utilisé dans les questions avec des mots interrogatifs.
    - **Structure :** N**が**V / N**が**Adj
    - **Templates :**
	    - どなた**が**[Action]ましたか？
        - [Name]さん**が**好きです。
        - [Person]**が**[Place]から来ました。
        

- ***を***
    - **Explications :** Marque l'objet direct d'un verbe transitif. Indique ce qui subit l'action du verbe.
    - **Structure :** N**を**V
    - **Templates :**
	    - [Subject]**を**勉強しています。
        - [Language]**を**話せます。
        

- ***に***
    - **Explications :** Particule polyvalente qui indique la destination, le lieu d'existence, le temps, ou l'objet indirect. Marque "où" (lieu statique), "à qui/quoi" (direction/destinataire).
    - **Structure :** N**に**V / N**に**います/あります
    - **Templates :**
	    - [Place]**に**住んでいました。
        - [Place]**に**ありました。
        - [Place]**に**行ったことがありますか？
        - 家**は**[Place]**に**ありました。
        

- ***で***
    - **Explications :** Indique le lieu où se déroule une action, ou le moyen/méthode utilisé pour faire quelque chose.
    - **Structure :** N**で**V
    - **Templates :**
	    - 大学**で**[Subject]を勉強しています。
        - [Place]**で**何をしていますか？
        

- ***から***
    - **Explications :** Indique le point de départ, l'origine ou la provenance. Signifie "de", "depuis", "à partir de".
    - **Structure :** N**から**V
    - **Templates :**
	    - [Place]**から**来ました。
        - [Place]**から**[Place]まで
        

- ***も***
    - **Explications :** Particule d'inclusion qui signifie "aussi", "également". Remplace は ou を pour ajouter une nuance d'inclusion.
    - **Structure :** N**も**V / N**も**Adj
    - **Templates :**
        - [Place]**も**行ったことがありますか？
        - [Language]**も**分かります。
        - [Person]**も**います。
        

- ***と***
    - **Explications :** Particule de liaison qui signifie "et" pour connecter des noms, ou "avec" pour indiquer l'accompagnement.
    - **Structure :** N**と**N / N**と**V
    - **Templates :**
    - [Language1]**と**[Language2]を話せます。
        - [Language1]**と**[Language2]は少し分かります。
